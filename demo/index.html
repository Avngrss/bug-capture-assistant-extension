Demo store for Bug Capture Assistant

Corner Shop

A tiny online store with bugs planted on purpose. Start capture, shop as usual, and see what the extension catches along the way.

Open the store

How to try it

  1. Install the extension: quick install.
  2. Open the store, click the extension icon, and press Start capture.
  3. Shop as usual: sign in (password demo1234), search, add items, change quantities, apply a promo code, check out.
  4. Press Stop and review, then Create ticket on any card.

Everything runs in your browser. The store's API is a Service Worker on this page, so there is no server and no data leaves your machine.
